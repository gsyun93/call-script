# 테이블오더 통화 스크립트

영업 담당자가 통화하면서 옆에 띄워 두는 내부용 웹 툴입니다.

## 여는 방법

`index.html`을 크롬이나 엣지로 더블클릭해서 엽니다. 설치나 서버는 필요 없습니다.

## 화면

- **스크립트**: 화면에는 버튼만 나옵니다. 버튼마다 고객 반응과 그 다음에 읽을 멘트가 같이 적혀 있어서, 버튼을 누르고 거기 적힌 멘트를 읽으면 됩니다. 숫자 키와 Enter로도 고를 수 있습니다. 맨 아래 `이전`(또는 Backspace)으로 되돌아가고, `처음으로`는 입력값은 두고 첫 화면으로 갑니다.
  - 위쪽 메뉴(금액표, 카톡 문구, 통화 기록, 새 통화, 결과 기록)는 평소에 숨어 있고, 마우스를 화면 맨 위로 올리면 내려옵니다.
  - 흐름: 오프닝(외부 유입, 에이전시 유입, 재통화) → 통화 가능 여부 → 매장 상황(운영 중 + 매장명, 오픈 준비 중 + 업종·오픈일, 기타 + 직접 입력) → 상담 메뉴(브랜드 소개, 니즈 파악, 견적 정보 확인) → 견적 → 클로징. 재통화에서 "견적 받아보신 분이에요"를 고르면 재컨택 멘트로 갑니다.
  - 브랜드 소개 화면에서는 니즈 파악 질문 3개(도입 계기, 알게 된 경로, 지금 기기 불편)와 견적 정보 확인으로 바로 넘어갑니다. 니즈 파악과 견적 정보 확인 버튼에는 안에 있는 항목 이름이 적혀 있습니다.
  - 니즈 파악 질문 아래에는 왼쪽에 `← 니즈 파악으로`, 오른쪽에 `견적 정보 확인으로 →`가 있습니다. 고객 답 버튼을 누르면 거기 적힌 강점 멘트를 읽고 바로 견적 정보 확인으로 넘어갑니다.
  - 답 버튼에 대응 멘트가 적혀 있고 그다음이 목록으로 돌아가는 것뿐이면, 따로 화면을 거치지 않고 목록으로 바로 돌아갑니다. 고객 답에 맞는 버튼(예: 인건비)을 누르면 해당 강점 멘트로 바로 넘어갑니다.
  - 견적 정보 확인은 인터넷·CCTV부터 나옵니다. 질문마다 고객 답 버튼을 누르면 빈칸(인터넷·CCTV, 대수, 전원 방식, 선불·후불, 포스, 타사 견적, 결정권자, 오픈 준비 매장은 오픈일)이 채워지고, 목록에는 채운 값이 흐리게 표시됩니다. 빈칸이 다 채워지면 견적 단계로 알아서 넘어가고, 그 전에는 남은 항목이 보입니다. 채운 값은 결과 기록 메모에도 들어갑니다.
  - 오픈 준비 중 매장은 "지금 포스·약정" 대신 "포스 준비"(아직 없으면 페이히어 포스 추천)와 "오픈 일정"이 나오고, 운영 중 매장은 "지금 포스·약정"이 나옵니다.
  - 업종·주문 방식은 후불형, 선불형, 카페형, 점심·저녁 전환 추천 멘트로 갑니다. 고른 주문 방식은 견적 계산기의 후불/선불 대수에 자동으로 들어갑니다. 인터넷·CCTV에서 "없대요"를 고르면 인터넷 결합이 자동으로 켜집니다.
  - 테이블 수·거치대 질문에서는 전원형(콘센트 있음, 전기 공사 예정)과 보조배터리형(콘센트 없음) 대수, 거치대(고정형, 탁상·액자형, 커버형, 벽걸이형) 대수를 칸에 따로 넣고 `입력 완료` 하나만 누릅니다. 묶음마다 읽을 멘트가 위에 있고(꾹 눌러 수정), 전원 방식과 거치대를 둘 다 넣어야 `입력 완료`가 열립니다. 전원 방식 대수의 합이 테이블오더 대수가 되고, 거치대 합계가 다르면 옆에 표시됩니다. 넣은 수량에 맞춰 버튼 멘트(전원형·배터리 섞기, 커버형 주의 등)가 바뀝니다.
  - 업종·주문 방식 질문에서는 주방 프린터 대수(기본 1)를 같이 넣고, 고객 답 버튼으로 선불형·후불형을 정합니다. 프린터가 2대 이상이면 멘트에 추가분 안내가 붙습니다.
  - 이미 확인한 질문과 그 화면에서 이미 눌렀던 버튼은 흐리게 보입니다.
  - 견적: 빈칸이 다 채워지면 단가 안내로 바로 넘어갑니다. 단가 안내 화면과 최종 금액 화면 위에는 매장, 주문 방식, 테이블오더(전원 방식), 거치대, 주방 프린터, 인터넷·CCTV, 포스, 혜택, 월 합계 요약이 나옵니다. 단가 안내 화면에 계산기가 붙어 있습니다. 후불·선불 대수, 무상 대수, 인터넷 결합, 혜택(광고 제거, 메뉴 사진, 보조배터리 여유분, 당일 상품권, 국민카드, 위약금 지원)을 고르면 다음 버튼 하나에 대수 할인, 포스 결합, 최종 월 금액이 한 번에 담깁니다. "승인" 표시가 붙은 혜택은 내부 승인이 필요합니다.
  - 타사 견적 화면에는 KT 하이오더, 티오더, 토스 안내 멘트가 읽는 카드로 보입니다(누르는 버튼 아님, 꾹 눌러 수정). 버튼은 "저희만 알아봤대요"와 "그래도 망설인대요" 두 개이고, 망설이면 고객이 한 말을 적고 `다음`을 누르면 견적 정보 확인으로 돌아갑니다.
  - 반론 버튼(비싸대요 등)을 누르면 반론 화면으로 넘어갑니다. "해결됐어요"는 원래 흐름으로, "그래도 망설인대요"는 고객이 한 말을 칸에 적고 다음 답변으로 갑니다(적은 말은 결과 기록 메모에 들어갑니다). 같은 화면의 다른 반론 답변은 참고용으로 아래에 보입니다. 홍보·리뷰 이야기는 견적 뒤에 "리뷰·홍보로 한 번 더" 버튼으로 씁니다.
  - 질문 화면의 답변 메모와 매장 상황은 결과 기록 메모에 자동으로 들어갑니다.
  - 다시 걸 날짜와 시간은 입력칸에 바로 칩니다. 날짜는 `10/28`, `1028`, `내일`, `모레`, 시간은 `3시`, `3시 반`, `15:30`, `오후 2시`처럼 쓰면 되고, 1~8시는 오후로 봅니다.
  - 화면 편집: 맨 아래 오른쪽 `화면 편집`을 누르면 버튼마다 `위로`, `아래로`, `이름`, `삭제`가 붙고, 맨 아래에 `+ 버튼 추가`(목록 화면은 `+ 항목 추가`)가 생깁니다. 버튼을 추가할 때 이름, 누르면 읽을 멘트, 그다음 갈 화면을 고르면 됩니다. 편집 중에도 버튼을 눌러 다른 화면으로 이동하면서 계속 고칠 수 있고, `저장`으로 마칩니다. 바꾼 내용은 이 브라우저에 저장되고 백업 파일에도 들어가며, `편집 전체 되돌리기`로 처음 상태로 돌립니다.
  - 멘트 수정: 멘트가 적힌 버튼을 0.6초 정도 꾹 누르면 수정 창이 뜹니다. 고친 멘트는 이 브라우저에 저장되고, `원래 멘트로`를 누르면 되돌아갑니다. `{store}`, `{n}` 같은 자리표시는 그대로 두면 입력한 값이 들어갑니다. 백업 파일에도 같이 저장됩니다.
- **반론 대응**: 오른쪽 패널. `/` 키를 누르고 고객이 한 말(비싸, 위약금, 포스 등)로 검색합니다. 답변 문장을 꾹 누르면 수정할 수 있습니다.
- **금액표**: 2026-10 통화 기준, 부가세 포함. 칸을 눌러 바로 고칠 수 있고, 맨 위 견적 계산 단가(후불, 선불, 포스 세트)를 바꾸면 스크립트 멘트와 견적 계산에도 반영됩니다. 고친 값은 이 브라우저에 저장되고 `금액표 원래대로`로 되돌립니다.
- **카톡 문구**: 견적서, 서류 요청, 가계약, 매장 사진 요청 등. 복사해서 바로 씁니다.
- **통화 기록**: 통화가 끝나면 상단의 `결과 기록`으로 감도(상/중/하)와 이유, 재컨택일을 남깁니다.

매장명, 대수, 오픈일, 다음 연락일은 스크립트 화면 안에서 해당 질문을 할 때 입력하고, 오프닝에서 고른 유입 경로는 자동으로 기록됩니다. 입력한 값은 이후 멘트와 카톡 문구에 들어갑니다.

## 기록 저장 위치

통화 기록은 각자 쓰는 브라우저 안에만 저장됩니다. 파이프드라이브에는 아무것도 보내지 않습니다.
브라우저 데이터를 지우면 기록도 지워지니 `백업 저장`으로 주기적으로 파일을 받아두세요. 다른 PC로 옮길 때는 `백업 불러오기`를 씁니다.

## 내용 수정

스크립트, 반론, 금액, 카톡 문구는 모두 `js/data.js`에 있습니다. 프로모션이 바뀌면 이 파일의 `prices`와 `priceBaseDate`를 고칩니다.

## 원본 데이터

`raw/`에 파이프드라이브 원본(고객 개인정보 포함)이 있습니다. 공유하거나 저장소에 올리지 마세요. `.gitignore`에 들어 있습니다.
